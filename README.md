# Longest Cubic Subsequence (LCubS)

CMPT 360 – Algorithm Design

This project implements two algorithms for finding the Longest Cubic Subsequence: an optimized brute-force baseline and a faster dynamic programming algorithm.

## Requirements
- Python 3
- No additional libraries required

## How to Run

1. Clone the repository:

   `git clone https://github.com/CRISSKE/AlgorithmDesign-.git`

2. Navigate to the project folder:

   `cd AlgorithmDesign-`

3. Run the algorithms:

   **Baseline Algorithm:**

   `python3 baseline.py`

   **Faster Algorithm:**

   `python3 fasterAlgo.py`

   **Experimental Evaluation:**

   `python3 experiment.py`

The experiment runs both algorithms on randomly generated strings and displays their average execution times in the terminal.
